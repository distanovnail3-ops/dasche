# Даша, с годовщиной ♡

Готовый сайт с объёмным Пушином: он замечает зрителя, достаёт фотографию, поздравляет и танцует под HIM — Gone With The Sin с 0:42. В лапках по кругу меняются четыре фотографии. Их можно листать стрелками, кнопками или точками; автоматическую смену можно остановить.

## Загрузить на GitHub Pages

1. Распакуй ZIP.
2. Создай репозиторий на GitHub. Для бесплатного GitHub Pages выбери **Public**.
3. В репозитории нажми **Add file → Upload files**. Перетащи **содержимое распакованного архива**, включая папку `assets`, и нажми **Commit changes**. Сам ZIP загружать не нужно. Файл `index.html` должен лежать прямо в корне репозитория.
4. Открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, затем **main** и **/(root)**. Нажми **Save**.
6. Когда публикация закончится, ссылка появится в этом же разделе. Открой её и нажми «Подойти к Пушину».

Сборка, npm install, ключи и серверная часть не нужны. Все пути относительные: сайт работает и в репозитории вида `username.github.io/repository/`.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что внутри

- `index.html`, `style.css` — страница и оформление.
- `app.js` — сценка, свет, музыка и танец.
- `pusheen.js` — геометрия модели Пушина.
- `gallery.js` — смена фотографий и управление.
- `config.js` — список фотографий, подписи и тайминги.
- `assets/` — все четыре фотографии, песня и локальная библиотека Three.js.
- `.nojekyll` — публикация обычного статического сайта.
- `preview.cjs` — необязательный локальный просмотр.

## Изменить фотографии или музыку

Открой `config.js`. В `PHOTOS` можно добавить или заменить пути к изображениям и подписи. Клади свои файлы в `assets/` и сохраняй точный регистр букв в именах. Вертикальные и горизонтальные фотографии показываются целиком, без растягивания и обрезки.

`PHOTO_INTERVAL = 5.5` задаёт паузу между сменами в секундах. `MUSIC_START = 42` задаёт начало песни. Музыкальный файл находится в `assets/song.mp3`.

## Посмотреть на компьютере

Если установлен Node.js, открой терминал в папке сайта и выполни:

```sh
node preview.cjs
```

Открой `http://127.0.0.1:4184`. Остановить просмотр — **Ctrl+C**. Прямое открытие `index.html` двойным щелчком не подходит: браузер ограничивает загрузку JavaScript-модулей через `file://`.

Музыка включается после нажатия кнопки. Озвучка поздравления использует голос браузера; его звучание зависит от устройства. Если голос недоступен, поздравление остаётся на экране, а музыка и анимация продолжаются.
